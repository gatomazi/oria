# Auditoria de ownership/escopo — Meta Ads e Google Ads

Contexto confirmado nesta rodada (além dos fatos já dados pelo lead):
- `LOJAS` tem **3 lojas reais hoje**: `sul`, `centro`, `norte` (server.js:58). Não é um cenário hipotético de "1 loja só" — a mistura de escopo já é um risco vivo.
- `admin/src/api/metaAds.ts:3-6` documenta a premissa de arquitetura por trás de tudo isto: *"a conexão é ÚNICA — não há uma por loja: o produto é 1 cliente = 1 loja, e o banco garante isso (meta_connections tem CHECK (id = 1))"*. Essa premissa está desatualizada frente às 3 lojas reais — é a causa-raiz do padrão caçado nesta auditoria.
- `requireAdmin` (server.js:1574-1580) é um único nível de admin, sem conceito de organização/tenant/role por loja — qualquer admin autenticado pode ler ou alterar a atribuição de QUALQUER loja. Não classificado nas categorias 1-6 (não é um bug de "recurso global em operação de loja", é ausência total de fronteira de tenant), mas relevante para a productização.
- `registrarAuditLog` (server.js:1236) só é chamado em server.js:3107, 13051, 13096, 13114 — nenhuma chamada nas rotas de seleção/atribuição de conta Meta ou Google Ads.

## Não verificado / observações sem classificação

- Não existe job agendado (`setInterval`) de sync automático para Google Ads equivalente a `jobIncrementalMeta`/`jobDiarioMeta`/`jobRenovarTokenMeta` — busquei `setInterval.*[Gg]oogle` em server.js e não houve match. O sync do Google Ads hoje só roda via rota manual (`/contas/sincronizar`, `/sync`). Não verificado se isso é intencional (feature ainda incompleta) ou lacuna operacional — fora do escopo desta auditoria de ownership.
- Não há endpoints de `entities`/`creatives`/`ads` por criativo para Google Ads (só existe `overview`) — assimetria de features entre os dois providers, não um achado de ownership.
- Não localizei nenhum outro caller de `metaContaSelecionada`/`contaGoogleAdsSelecionada` além dos listados; a lista dada pelo lead (~11169, 11228, 11238, 11444, 11533, 11568, 11628, 11738, 11801, 12253, 11923, 11956 para Meta; ~10481, 10648, 10669, 11936 para Google Ads) bateu exatamente com o grep — confirmada e completa, sem chamadas adicionais.
