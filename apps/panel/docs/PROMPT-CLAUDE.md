# Prompt para o Claude usar os skills de frontend

Use os skills de frontend disponíveis neste projeto.

A referência visual anexada é a direção principal do layout.

Antes de escrever código:
1. aplique `reference-ui-implementation` se houver screenshot/mockup;
2. aplique `dashboard-ui-director` para composição e UX;
3. aplique `design-system-guardian` antes de criar estilos/componentes locais;
4. defina comportamento responsivo com `responsive-accessibility`;
5. apresente um plano curto de estrutura, tokens e componentes.

Depois implemente preservando as regras de negócio existentes.

Ao terminar:
- execute a aplicação;
- capture uma screenshot na mesma proporção da referência;
- aplique `visual-qa-reviewer`;
- compare implementação x referência;
- corrija os 5 maiores desvios visuais;
- capture novamente antes de considerar concluído.

Não trate o mockup como inspiração solta.
Não faça apenas uma troca de cores.
Não replique CSS isolado por página.
A implementação deve parecer parte de um único produto e seguir a direção dark premium aprovada.
